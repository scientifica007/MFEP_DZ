# Schemas

هذا المجلد مخصص لعقود البيانات الآلية للمشروع.

## الحالة الحالية

لم يتم تثبيت `legal-text.schema.json` نهائيا بعد. القرار المنهجي هو اختبار نموذج `docs/DATA_MODEL.md` على مجموعة من 5–10 نصوص قانونية متنوعة أولا، ثم استخراج JSON Schema من الحالات الفعلية.

السبب: تثبيت Schema نظري قبل اختبار حالات القانون والأمر والمرسوم والقرار المشترك والعمل الفردي والإلغاء الجزئي قد يؤدي إلى نموذج جامد أو خاطئ.

## معايير الانتقال إلى Schema مستقر

قبل إصدار `v1` يجب اختبار:

1. قانون؛
2. أمر؛
3. مرسوم رئاسي بوظيفة غير تنظيمية عامة (مثل التصديق عند وجود حالة مناسبة)؛
4. مرسوم تنفيذي تطبيقي؛
5. قرار وزاري مشترك؛
6. عمل إداري فردي؛
7. تعليمة/منشور مهم للقطاع؛
8. نص معدل عدة مرات؛
9. نص ملغى جزئيا؛
10. نص تاريخي تغيرت تسمية الجهة التي أصدرته.

## مبدأ التوافق

بعد إصدار `v1`، أي تغيير يكسر التوافق يجب أن يوثق كقرار منهجي مع migration واضح للبيانات القديمة.
