# corpus/texts — النصوص القانونية القابلة للقراءة والاستدعاء

هذا هو **المسار الدائم** لكل نص قانوني بعد انتقاله من مرحلة التجريب إلى البنية الموحدة Human + Machine.

## المبدأ

كل نص يصبح مجلدا مستقلا:

```text
corpus/texts/<TEXT_ID>/
├── README.md              # واجهة الإنسان
├── record.yml             # السجل المهيكل
├── text/
│   ├── ar.md              # transcription العربية
│   └── fr.md              # transcription الفرنسية
├── data/
│   └── articles.jsonl     # استدعاء على مستوى المادة
└── sources/
    └── sources.yml        # روابط ومحددات المصدر الرسمي
```

لا تحفظ ملفات PDF داخل هذا المسار أو أي مكان في المستودع.

## النصوص التي انتقلت إلى النموذج الدائم

- [`DZ-LAW-2008-007`](DZ-LAW-2008-007/README.md) — القانون التوجيهي للتكوين والتعليم المهنيين.

## حالات المحتوى النصي

- `transcription_pending`: المصدر محدد، لكن المتن النصي الداخلي لم يعتمد بعد.
- `transcribed`: نُقل المتن نصيا لكنه يحتاج مراجعة.
- `verified`: تمت مراجعته مقابل المصدر الرسمي، ومع العربية يمكن استخدام المقابلة الفرنسية عند فساد الاستخراج.

## قاعدة مهمة

وجود `README.md` أو `articles.jsonl` لا يعني أن المتن الرسمي الكامل أصبح داخليا. يجب قراءة حالة `text/ar.md` و`text/fr.md` وحقول verification في `record.yml`.

## الهجرة

السجلات الباقية تحت `corpus/staging/` ستنقل تدريجيا إلى هذا الشكل بعد التحقق من بنيتها والمصادر. لا ننشئ نسختين دائمتي الحقيقة لنفس النص؛ عند اكتمال النقل يحدث metadata ثم تحذف نسخة السجل القديمة.
