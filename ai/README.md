# طبقة الذكاء الاصطناعي في MFEP_DZ

الغرض من هذا المجلد هو جعل المشروع **Model-Agnostic** و**Provider-Agnostic**: يمكن تبديل ChatGPT أو Claude أو Gemini أو نموذج محلي دون تغيير الحقيقة القانونية أو بنية corpus.

## المبدأ المعماري

الذكاء الاصطناعي **عامل معالجة واستدلال فوق قاعدة المعرفة، وليس مصدر الحقيقة القانونية**.

```text
official sources
      ↓
raw evidence
      ↓
normalization
      ↓
AI-assisted extraction / interpretation
      ↓
validation + evidence checks
      ↓
trusted corpus / metadata / graph
```

لا يجوز عكس السهم بحيث تصبح إجابة النموذج هي الدليل.

## مكونات الطبقة

- `AGENT_CONTRACT.md` — القواعد غير المرتبطة بمزود بعينه.
- `PROJECT_CONTEXT.md` — سياق مكثف لأي نموذج جديد.
- `HANDOFF.md` — أين وصل المشروع وما الذي يلي.
- `SAFETY_AND_LIMITS.md` — حدود الأتمتة ومناطق الخطورة القانونية والبيانية.
- `context/` — تمثيلات JSON للسياق والسياسات الأساسية.
- `tasks/` — مواصفات مهام مستقلة عن المزود.
- `prompts/` — prompts قابلة للإصدار عند الحاجة، ولا تحتوي الحقيقة القانونية التي يجب أن تكون في corpus.
- `context-packs/` — سياقات موضوعية صغيرة للنماذج ذات نافذة سياق محدودة.
- `outputs/` — مواصفات المخرجات المؤقتة قبل اعتمادها في corpus.
- `evals/` — اختبارات مرجعية لمقارنة نموذج أو prompt أو pipeline جديد بالنتائج المتوقعة.
- `adapters/` — واجهة عزل مزود الذكاء الاصطناعي عند بناء برامج أو أتمتة.

## ثلاث طبقات يجب عدم خلطها

1. **Knowledge**: النصوص والمراجع والعلاقات القانونية والبيانات المثبتة.
2. **Method**: المنهج والـschema والـontology وقواعد التحقق.
3. **AI execution**: النموذج، prompt، مزود API، temperature، run logs.

تغيير الطبقة الثالثة يجب ألا يغير الأولى أو الثانية إلا عبر تغيير مراجع ومدقق ومُسجل.

## قاعدة قبول نموذج جديد

لا يسمح لنموذج أو prompt أو pipeline جديد بالكتابة مباشرة في corpus الموثوق قبل اختباره على مجموعة `ai/evals/` المناسبة. الحد الأدنى المقبول ليس نسبة عامة واحدة؛ يجب خصوصا منع الأخطاء عالية الضرر مثل:

- اختلاق الإلغاء أو النفاذ؛
- الخلط بين `references` و`amends`؛
- دمج نص فرنسي مستعاد في العربية وكأنه النص العربي الرسمي؛
- فقدان provenance؛
- تغيير رقم أو تاريخ نص قانوني بصمت.

## قابلية العمل دون مزود معين

يجب أن يستطيع Agent جديد، بعد نسخ المستودع وقراءة `AGENTS.md` وهذا المجلد، فهم:

- ما المشروع؛
- ما مصادر الحقيقة؛
- كيف يعالج النص؛
- كيف يمثل عدم اليقين؛
- ما المخرجات المتوقعة؛
- ما العمل الجاري؛
- وكيف يُختبر قبل أن يصبح موثوقا.
