# مهام الذكاء الاصطناعي القياسية

كل ملف هنا يصف **عقد مهمة** مستقلا عن المزود والنموذج. الهدف هو أن يحصل أي Agent على نفس المدخلات، يتبع نفس الخطوات، وينتج مخرجات قابلة للتحقق.

## المهام الأولية

- `discover-legal-text.md` — اكتشاف مرشح نص رسمي وتثبيت مرجعه.
- `ingest-legal-text.md` — إدخال نص من المصدر إلى staging record.
- `align-ar-fr.md` — مقابلة العربية والفرنسية عند الحاجة.
- `extract-relations.md` — استخراج العلاقات القانونية مع evidence.
- `determine-status.md` — تحديد الحالة القانونية في تاريخ معين.
- `update-knowledge-graph.md` — تحديث الحواف والفهارس من بيانات موثقة.

## قاعدة التنفيذ

لا تُختصر المهمة إلى «حلل النص». يجب تحديد:

- input؛
- required sources؛
- process؛
- output contract؛
- validation؛
- failure/uncertainty behavior.

عند غياب معلومة مطلوبة لا يملأها النموذج تخمينا؛ يسجلها كقيمة غير متحققة أو يعيد مسألة تحتاج بحثا.
