# Context Packs

الـContext Pack حزمة صغيرة مخصصة لموضوع أو مهمة حتى لا يحتاج النموذج إلى تحميل كامل المستودع في كل مرة.

## أمثلة مستقبلية

- `personnel/`
- `apprenticeship/`
- `institutions/`
- `inspection/`
- `exams-certification/`

## ما تحتويه الحزمة

- مقتطف ontology ذي صلة؛
- taxonomy ذات صلة؛
- معرفات النصوص المؤسسة المعتمدة؛
- المصطلحات AR/FR/EN ذات الصلة؛
- task contract المناسب؛
- مسائل مفتوحة خاصة بالمجال.

## ما لا تحتويه

- حقائق قانونية غير موجودة في corpus؛
- نسخ خاصة بمزود دون ضرورة؛
- معلومات من محادثة غير موثقة؛
- تعميمات تحل محل المصادر الرسمية.

الحزمة هي **وسيلة توزيع للسياق** وليست مصدر حقيقة جديدا.
