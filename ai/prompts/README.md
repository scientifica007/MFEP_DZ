# Prompts

هذا المجلد مخصص فقط للقوالب التنفيذية التي قد تحتاجها النماذج، وليس لحفظ الحقيقة القانونية.

## قواعد

1. لا تضع معلومة قانونية متغيرة داخل prompt إذا كان مكانها corpus أو metadata.
2. كل prompt مؤثر في الاستخراج أو التصنيف يجب أن يكون versioned في Git.
3. أي تغيير جوهري في prompt يجب أن يختبر على `ai/evals/` قبل اعتماد نتائجه في trusted corpus.
4. prompt يحدد **كيف تنفذ المهمة**؛ ملف `ai/tasks/` يحدد **عقد المهمة**؛ والـschema يحدد **شكل الناتج**.
5. لا تنشئ نسخا مستقلة خاصة بكل مزود إلا عند وجود فرق تقني حقيقي، ويجب أن تحافظ كلها على نفس task contract.

## تسمية مقترحة

```text
extract-relations-v1.md
extract-relations-v2.md
```

وعند الانتقال إلى إصدار جديد يسجل سبب التغيير، خاصة إذا كان لمعالجة failure case ظهر في evals.
