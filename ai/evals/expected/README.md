# المخرجات المتوقعة Gold Outputs

يوضع هنا الناتج المرجعي لكل حالة في `../cases/` بعد التحقق من المصدر الرسمي ومراجعة العلاقة أو الحالة القانونية.

## شروط Gold Output

- المصدر الرسمي مثبت.
- القيم القانونية الحرجة مربوطة بـevidence.
- أي استخدام للفرنسية في استعادة العربية أو البنية مسجل.
- عدم اليقين محفوظ إذا لم يمكن الحسم.
- النتيجة لا تُبنى على إجماع نماذج ذكاء اصطناعي؛ بل على التحقق القانوني/المصدري.

## صيغة مقترحة

يفضل أن تكون النتائج Structured (JSON/YAML) وقابلة للمقارنة الآلية، مع ملف Markdown قصير عند الحاجة لتفسير سبب اختيار علاقة أو حالة معينة.

## الإصدار

عند تصحيح Gold Output بسبب اكتشاف مرجع أفضل أو خطأ سابق، يجب تسجيل التغيير في `KNOWLEDGE_CHANGELOG.md` لأن تغيير gold standard يؤثر في تقييم جميع النماذج.
